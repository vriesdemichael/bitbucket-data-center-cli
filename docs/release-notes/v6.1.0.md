bb v6.1.0 gives administrators who set bb's policy through Group Policy a template to do it with, and sets up shell completion for Windows PowerShell 5.1 when you run the setup from PowerShell 7.

It is a minor release with no breaking changes.

### For administrators

* **A Group Policy template for bb's Windows policy ([#776](https://github.com/vriesdemichael/bitbucket-data-center-cli/issues/776)):**

  bb reads its machine policy from `HKEY_LOCAL_MACHINE\Software\Policies\bb`, but there was no administrative template for it, so setting it through Group Policy meant writing registry items by hand. Each release now publishes `bb_policy_templates.zip`, holding `bb.admx` and `en-US/bb.adml`. Extract it into the `PolicyDefinitions` folder of your central store, and every value bb reads is a setting under **Computer Configuration > Administrative Templates > bb, the Bitbucket Data Center CLI**, with help that names the registry value it writes. Take the template from the release you deploy, since it offers the values that release reads. [Fleet deployment](https://vriesdemichael.github.io/bitbucket-data-center-cli/latest/advanced/fleet-deployment/#group-policy) has the steps.

### Fixes worth knowing

* **`bb completion install` run from PowerShell 7 sets up Windows PowerShell 5.1 as well ([#819](https://github.com/vriesdemichael/bitbucket-data-center-cli/issues/819)):**

  It set PowerShell 7 up, then printed a block of PowerShell error text and left Windows PowerShell 5.1 without completion. Both are set up now, and `bb doctor` and `bb completion remove` find the 5.1 profile too. If you ran the setup from PowerShell 7 before, run it again to add 5.1:

  ```bash
  bb completion install --shell powershell
  ```
